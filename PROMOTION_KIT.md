## Longer Reddit / Forum Post

Title: Independent local-control app for legacy Wemo devices

Hi, we are Meonmesh Apps. We have been working on Wemo Controller, an independent app for compatible legacy Wemo plugs, switches, dimmers, and Insight devices.

The goal is simple: keep existing Wemo hardware useful when it still works on the local Wi-Fi/LAN. The app does not require a Belkin cloud account and does not provide outside-home remote access. It talks to compatible devices locally using the local services exposed by the devices.

What it currently does:

- Finds compatible Wemo devices on the local network
- Saves known devices as Things
- Refreshes on/off state
- Sends guarded on/off commands and confirms state afterward
- Supports dimmer brightness where compatible local services are available
- Shows Insight power usage where compatible local services are available
- Lets older devices be found by IP address if automatic discovery misses them

Android is available now:
https://play.google.com/store/apps/details?id=com.meonmesh.lot.wemocontroller

The iOS version has been submitted to App Review.

Limitations:

- Phone/tablet must be on the same Wi-Fi/LAN as the Wemo devices
- No Belkin cloud remote access
- No Matter control
- No HomeKit/HAP control
- No Google Home integration in the iOS version
- Not every Wemo model is guaranteed to work

Independent project. Not affiliated with or endorsed by Belkin or Wemo. Feedback and bug reports are useful, especially for older models.

## Reply For People Asking Whether It Is Official

No. Wemo Controller is independent software and is not affiliated with or endorsed by Belkin or Wemo. The Wemo name is used only to identify compatible legacy devices.

## Reply For People Asking About Remote Access

Wemo Controller is local only. Your phone or tablet must be on the same Wi-Fi/LAN as the Wemo devices. It does not provide internet remote access or a cloud bridge.

## Reply For People Asking About Matter / HomeKit

The app does not implement Matter or HomeKit/HAP control. It uses local Wemo device services where compatible devices expose them.
